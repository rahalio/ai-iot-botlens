# BotLens — User stories

**Product:** [PRODUCT.md](./PRODUCT.md)


### SOC analyst

- As a SOC analyst, I want sub-second alerts when an IoT device’s traffic snapshot fails reconstruction, so I can quarantine before DDoS peaks.
- As a SOC analyst, I want evidence of which feature groups drove reconstruction error, so I can confirm spoofing or flood behaviors.
- As a SOC analyst, I want to mark an alert as benign rare event, so voting windows and thresholds can be retuned without silencing the device forever.

### Network engineer

- As a network engineer, I want automatic NAC quarantine hooks, so response is not ticket latency.
- As a network engineer, I want learning-mode VLANs for new devices, so training windows are enforced.

### IoT governance lead

- As a governance lead, I want predictability scores on device classes, so procurement can refuse unmonitorable gadgets on critical networks.
- As a governance lead, I want coverage of modeled vs unmodeled inventory, so BYOIoT gaps are visible.

### Detection engineer

- As a detection engineer, I want per-device autoencoder training jobs with benign provenance, so models are auditable.
- As a detection engineer, I want FPR/TPR dashboards by device class after Mirai/BASHLITE-like drills, so readiness is tested.

### Compliance officer

- As a compliance officer, I want retention limits on flow statistics, so monitoring stays purpose-bound.
- As a compliance officer, I want proof that quarantine actions were policy-driven, so availability incidents on clinical IoT are defensible.
